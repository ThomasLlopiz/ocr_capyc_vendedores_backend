# Flujo general del backend

1. **Autenticación y usuarios**
   - AuthController gestiona login, registro y verificación.
   - User.php es el modelo de usuarios.
   - Las rutas de autenticación están en routes/api.php.

2. **Empresas y órdenes**
   - EmpresaController gestiona CRUD de empresas.
   - ProcessOrderController y SB1Controller procesan órdenes y datos relacionados.
   - SC5010Controller y SC6010Controller gestionan entidades SC5010 y SC6010.
   - Los modelos Empresa, SC5010 y SC6010 representan las tablas respectivas.

3. **Procesamiento de datos**
   - JsonController recibe y procesa datos JSON enviados desde el frontend.
   - DA0DatateController y otros controladores pueden manejar lógica específica de negocio.

4. **Base de datos**
   - migrations/ contiene los scripts para crear tablas (usuarios, empresas, órdenes, tokens, etc.).
   - seeders/ permite poblar la base de datos con datos iniciales.
   - database.sqlite almacena la información persistente.

5. **Middleware y servicios**
   - ForceJsonResponse fuerza que todas las respuestas sean en formato JSON.
   - AppServiceProvider configura servicios globales de la aplicación.

6. **Rutas**
   - api.php define los endpoints de la API REST.
   - console.php define comandos de consola personalizados.
   - web.php define rutas web (si la app tiene vistas web).
